This is a small indie development project made in godot

What you need:

1. git  https://git-scm.com/
2. godot  https://godotengine.org/download/windows/

To access in godot:

1. in file location open git bash
2. make sure git bash is set to this github
3. type "git pull"
4. you should see the files change
5. open in godot


To save changes in github:

1. save changes in godot
2. open git bash in the game file
3. "git status"
4. "git add ."
5. "git commit -m "[Your message here]""
6. "git push"

To check if it works:
Type your github username under the test file in art assets
