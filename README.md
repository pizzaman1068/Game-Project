This is a small indie development project made in godot


To access in godot:

1. in file location open git bash
2. make sure git bash is set to this github
3. type "git pull"
4. you should see the files change
5. open in godot


To update github:

1. save changes in godot
2. open git bash in the game file
3. "git status"
4. "git add ."
5. "git commit -m "<Your message here>""
6. "git push"
